# 捣蛋助手

三角洲行动交易行**全自动监测买入**工具：打开游戏窗口即自动 OCR 盯价、低价秒买，
无需任何热键。界面采用三角洲官方视觉主题，支持电脑与手机（ADB）双平台。

## 功能

### 全自动监测（无热键）

- **打开游戏即监测**：程序后台每秒检测三角洲游戏窗口（16:9），窗口一出现立即
  开始轮询所有已启用的子弹任务；窗口关闭自动挂起等待，零操作
- **常驻 OCR 引擎**：Windows 自带 OCR，单次识别约 40~60ms
- **零延迟键鼠**：Win32 `SendInput` 直接注入，抢单关键路径毫秒级完成
- 勾选即蹲：在"目标子弹"页勾选子弹即自动纳入监测；买满设定次数自动停用该弹

### 目标子弹库（53 种）

- 收录官方全部**可交易**弹种：5.56 / 5.45 / 5.8 / 7.62x39 / 7.62x51 / 7.62x54R /
  9x39 / 9x19 / 4.6x30 / 5.7x28 / 6.8x51 / 12.7x55 / 12号霰弹 / .45 ACP /
  .300 BLK / .50 AE / .357，按穿透等级 T0~T5 彩色标注
- 每种子弹独立设置：**买入价格 / 最低档位 / 最高档位 / 最大买入数量 / 购买次数**
- 按等级或口径筛选，一键过滤 T3/T4 常用弹

### 三档价格决策

| 价格区间 | 动作 |
|---|---|
| ≤ 买入价格 | 立即按"最大买入数量"秒买 |
| 买入价 ~ 最低档位 | 小额买入（31 发）快速刷新 |
| 最低档 ~ 最高档 | ESC 免费刷新等待降价 |
| > 最高档位 | 免费刷新盯守（日志标红） |

### OCR 监测页

- 顶部状态灯：绿色=监测中 / 黄色=等待游戏窗口 / 红色=未启动
- 彩色日志流：买入=绿、完成=绿粗、注意=黄、异常=红、监测=蓝
- 一键启动三角洲行动（路径在设置页配置）

### 界面

- 三角洲官方主题：logo 绿 + 危险橙 + 战场深色底，官方图标
- 三个页面：**目标子弹**（弹种库+价格）、**OCR 监测**（状态灯+日志）、**设置**
- 游戏内彩色日志浮层：小字号、点击穿透、嵌在游戏窗口左上角
- 配置自动保存，旧版配置自动迁移合并进新弹库

### 双平台

- **电脑模式**：模拟键鼠 + 屏幕截图 OCR
- **手机模式**：ADB 点击 + 截图回传 OCR；位置通过"截图取点"在手机截图上直接点击标定；
  日志浮层显示在电脑屏幕右上角

## 依赖

```text
PyQt5
pyautogui
Pillow
```

OCR 使用 Windows 10/11 自带 `Windows.Media.Ocr`，无需下载模型。
手机模式需 [adb platform-tools](https://developer.android.com/tools/releases/platform-tools)。

## 安装 / 启动

双击桌面"捣蛋助手"快捷方式，或：

```powershell
cd E:\捣蛋
.venv\Scripts\python.exe main.py
```

程序会申请管理员权限（模拟鼠标点击需要）。单实例保护，重复双击不会开多个窗口。

## 使用

1. 首次使用：设置页选好游戏路径（可一键启动）；"目标子弹"页勾选要蹲的子弹、
   确认三档价格和最大买入数量
2. 选中子弹 → 点"记录选中子弹位置"→ 3 秒内把鼠标移到交易行里该子弹上（每弹一次）
3. 打开"自动监测"开关（默认开）→ 启动游戏进交易行 → 程序自动开始盯价买入
4. "OCR 监测"页实时查看每一次比价与买入；F9 已移除，不想蹲了关掉开关即可

## 风险提示

脚本只负责低价买入，不涉及内存修改。自动操作仍可能违反游戏用户协议，请自行评估风险。
